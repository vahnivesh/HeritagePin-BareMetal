HERITAGE PIN / BAREMETAL

Discovery without the middleman.

Heritage Pin anchors a living heritage profile to the place where the craft exists. Initial onboarding happens through Telegram, so the custodian does not need to operate a complex storefront.

After the verification flow, the system creates a unique Heritage ID and password. The public pin starts as NOT CLAIMED. The custodian can later claim it and manage the profile directly.

This demo stores profile metadata in Firebase Realtime Database. Firebase Storage is intentionally not used.
